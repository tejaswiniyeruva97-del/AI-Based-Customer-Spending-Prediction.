# AI-Based-Customer-Spending-Prediction.
## Project Overview
This project predicts whether a customer belongs to a Low, Medium, or High spending category using customer demographic and purchasing information.

## Objectives
- Clean and prepare customer data.
- Perform Exploratory Data Analysis (EDA).
- Create useful features.
- Apply data preprocessing.
- Train Machine Learning models.
- Evaluate model performance.

## Tools and Technologies
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn
- Google Colab

## Project Workflow

### 1. Data Collection
Load the customer dataset using Pandas.

### 2. Data Understanding
- Display first five rows.
- Check dataset information.
- Check rows and columns.
- Identify data types.

### 3. Data Cleaning
- Check missing values.
- Remove duplicate records.
- Handle missing values.

### 4. Exploratory Data Analysis
Create five visualizations:
- Histogram
- Box Plot
- Correlation Heatmap
- Count Plot
- Scatter Plot

### 5. Feature Engineering
Create useful features from existing customer information.

### 6. Data Preprocessing
- Encode categorical variables.
- Scale numerical features.
- Separate input and output variables.

### 7. Model Training
Train two Machine Learning models:
- Logistic Regression
- Decision Tree Classifier

### 8. Model Evaluation
Evaluate model performance using:
- Accuracy Score
- Precision
- Recall
- F1 Score
- Classification Report

## Expected Deliverables
1. Cleaned customer dataset.
2. EDA notebook with at least five visualizations.
3. Feature engineering and preprocessing.
4. At least two Machine Learning classification models.

## Expected Output
Predict customer spending categories:
- Low Spending
- Medium Spending
- High Spending

## Conclusion
This project demonstrates the basic Machine Learning workflow for customer spending prediction using Python and Scikit-learn.
